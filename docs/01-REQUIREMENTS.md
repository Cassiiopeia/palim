# 01. 요구사항 — AI 업무자동화 모듈

> 2026-08-06 발주사 협의로 확정된 방향. 재고 알림 시스템 요구사항(구 버전)은
> `archive/2026-08-07-requirements-frozen.md` 로 동결 이관.

발주사의 반복 업무를 **모듈 단위로 자동화**한다. 모듈은 하나씩 만들어 공유·검수 후 다음으로
넘어가며, 각 모듈은 착수 전 **A4 한 장 범위서**(입력·출력·안 되는 것·수정 2회 포함)에 합의한다.

## 모듈 카탈로그

### 영업 (판매·정산 데이터)

| 모듈 | 내용 | 비고 |
|---|---|---|
| 판매 브리핑 | 매일 아침 전일 판매 요약 + AI 코멘트 → 텔레그램 | 날씨·요일 데이터는 기록만 병행(§제외 3) |
| 리뷰 분석 | 판매자센터 리뷰 엑셀 업로드 → 분류(불만/칭찬 카테고리)·요약 리포트 | 공개 페이지 자동 수집은 옵션(구독 조건) |
| 정산 분석 | 채널별 정산 엑셀 업로드 → 정규화·수수료 분석 리포트 | 채널별 파서 추가 방식 |
| 재고 대사 | ERP ↔ 3PL 재고 엑셀 대조 → 불일치 리포트 | |
| 경쟁사 모니터링 | 지정 상품 페이지 주기 수집 → 가격·리뷰 변동 알림 | **유지보수 구독 필수** — 페이지 구조 변경 시 깨지는 유형 |
| CS 분석 | 문의 데이터 분류·경향 리포트 | 수집 경로 확정 후 |
| 수입 예측 | 판매 추이 기반 예측 | **장기** — 데이터 축적 후 |

### 마케팅 (유튜브·인스타)

| 모듈 | 내용 | 비고 |
|---|---|---|
| 인플루언서 등급표 | 랭킹 서비스+유튜브 API 발굴 → 인스타 교차 매핑 → 공식 API 정량 수집 → 참여율 기반 등급 + 적합도 코멘트 | 전부 공식 API. 개인 계정은 "조회 불가" 표시 |
| DM 초안 생성 | 등급표에서 선별 → 개인화 메시지 초안 자동 생성 → **발송은 사람이** | 콜드 DM 자동 발송은 §제외 1 |
| 영상 분석 | 영상 링크 → 자막·음성 텍스트화 → 구조 분석(후킹·전개·CTA) | 상중하 평가는 기준 영상 2~3개로 루브릭 합의 선행 |
| 스크립트 생성 | 영상 분석 결과 + 제품 소구 포인트 → 스크립트 초안 | |

### 디자인

| 모듈 | 내용 | 비고 |
|---|---|---|
| 조건부 리사이징 | 채널별 규격 프리셋 → 일괄 변환 | 1호 모듈 |
| 이미지 검수 | OCR 오탈자 교정(자동) + 레이아웃 의심 항목 하이라이트(반자동) | §제외 2 |
| SNS 리포트 | 본인 계정 인사이트 API → 주간 리포트(추이 축적·유형별 비교) | 앱 수치 단순 복사 리포트는 만들지 않는다 |
| 상세페이지 분석 | 자사몰=행동 데이터 정량 / 마켓 페이지=AI 구조 분석+리뷰 소구점 결합 정성 제안 | 마켓 페이지에는 스크립트 삽입 불가 |

## 명시적 제외 (합의된 선)

1. **DM 자동 발송** — 플랫폼 정책상 불가·계정 정지 위험. 초안 생성까지만
2. **이미지 검수 100% 자동 판정** — 반자동(하이라이트+사람 확인)으로 한정
3. **조기 날씨·판매 상관 분석** — 데이터 6개월+ 축적 전에는 기록만. 통계적 근거 없는 주장 금지
4. **비공식 크롤링 자동화** — **남의** 로그인 영역을 긁지 않는다. 공개 페이지 수집은
   유지보수 구독 조건으로만
   - 예외는 **발주사 자기 계정으로 자기 자료를 받아오는 경우**다. 물류 원천이 여기 해당한다 —
     공개 API 가 유료라, 발주사가 준 계정으로 로그인해 그 화면이 부르는 조회 요청을 그대로
     부른다. 남의 자료를 몰래 가져오는 것과는 다른 일이라 선을 다시 그었다 (→ 07-DECISIONS 029)

## 인수 방식

- 모듈별 범위서 서명 → 구현 → 공유·검수 → 수정 2회 이내 반영 → 인수
- 수정 2회 초과분·범위 외 요청은 별도 협의
- AI 판단 기준(분류 카테고리·평가 루브릭·등급 기준)은 발주사와 합의한 문서를 원본으로 하며,
  변경 시 문서를 먼저 갱신한다
