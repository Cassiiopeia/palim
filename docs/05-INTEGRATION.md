# 05. 외부 연동

> 구 채널 어댑터(주문 수집) 연동은 동결되었다 — `archive/channels/` 참조.
> 현행 연동 대상: AI API · 유튜브 · 인스타 · 텔레그램 · 외부 도구(yt-dlp).

## AI API (OpenAI)

| 항목 | 결정 |
|---|---|
| 호출 | **Spring 서비스에서 직접 HTTP 호출**(`RestClient`) — py 경유 금지. 공식 SDK 를 넣지 않는 이유는 쓰는 표면이 채팅 완성 한 엔드포인트뿐이라 얻는 것이 적고, SDK 버전이 내부망 미러 사정에 빌드를 묶기 때문이다. 텔레그램 클라이언트와 같은 방식이다 |
| 모델 | 저비용 티어 기본(대량 분류·요약), 필요 시 상위 티어 — 모델명은 설정값으로, 코드에 하드코딩 금지 |
| 출력 | **항상 구조화 출력(json_schema, strict)** — 자유 텍스트 파싱 금지. 스키마 검증 실패는 재시도 1회 후 실패 처리 |
| 키 | 환경변수. **사용량 한도(hard limit) 설정된 키만 사용** |
| 데이터 경계 | 필요한 컬럼만 전송. 개인 식별자·연락처는 마스킹 후 전송. 리뷰 등 외부 텍스트는 "데이터"로만 취급(프롬프트 인젝션 방어 — AI 출력으로 임의 동작 실행 금지) |
| 프롬프트 | 판단 기준(분류 카테고리·루브릭)은 발주사 합의 문서가 원본. 프롬프트는 리소스 파일로 버전 관리 |

## 유튜브 Data API

- 무료 쿼터 일 10,000 유닛 — 검색 100유닛/회, 채널 통계 1유닛/회
- 용도: 인플루언서 발굴(카테고리 검색) + 채널 정량 지표 수집
- 채널 설명·링크에서 인스타 핸들 추출 → 인스타 교차 매핑의 입력

## Meta Graph API (인스타)

| 기능 | 가능 여부 |
|---|---|
| 본인 계정 인사이트 | O — SNS 리포트의 데이터 소스 |
| Business Discovery (타인 비즈니스/크리에이터 계정 팔로워·게시물 지표) | O |
| Hashtag Search | O — 주 30개 해시태그/계정 제한 |
| 콜드 DM 발송 | **X** — Messaging API 는 수신 응답용. 우회 자동화 금지(계정 정지 위험) |
| 개인 계정 조회 | X — 등급표에 "조회 불가" 표시 |

- Standard Access(앱에 role 있는 본인 계정)면 앱 검수·사업자 인증 불필요. API 무료
- 토큰은 환경변수·DB 암호화 저장 — 화면·로그 노출 금지

## 텔레그램 (브릿지 — 기존 자산 재사용)

- `palim-notification` 의 Outbox·발송·이력 구조를 그대로 쓴다. **직접 봇 API 호출 금지**
- 발송 실패는 결과 객체(07-DECISIONS 011), 재발송은 알림 이력 화면에서 수동
- 용도: 판매 브리핑, 모듈 처리 완료/실패 알림, 경쟁사 변동 알림

## 외부 도구 (py 스크립트 경유)

| 도구 | 용도 | 방식 |
|---|---|---|
| yt-dlp | 영상·자막 다운로드 | `scripts/video_fetch.py` — Docker 이미지에 포함, 버전 고정 |
| 음성→텍스트 | 자막 없는 영상 | OpenAI 음성 API 호출 (로컬 모델 안 씀) |
| pandas/openpyxl | 엑셀 파싱·정규화 | `scripts/parse_excel.py` — 표준 스키마(JSON) 출력 |

## 엑셀 업로드 입력 경계 (공통)

```
[업로드 xlsx] → (py) 헤더+샘플 → AI 컬럼 매핑 추론(1회, 구조화 출력)
             → (py) pandas 전체 파싱 → 표준 스키마 JSON
             → (Java) 집계·저장 — 숫자 계산은 전부 코드, AI 는 분류·코멘트만
```

- 파일 검증: 확장자·매직 바이트·크기 상한 (09-SECURITY 파일 규칙)
- 파싱은 py 서브프로세스 안 — 파서 취약점을 JVM 과 격리
- 알 수 없는 형식: 컬럼 매핑 추론 실패 시 사용자에게 매핑 확인 화면 제시 (조용히 틀리게 파싱하지 않는다)
