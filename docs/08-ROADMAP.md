## 개발 웨이브

### W1 — 즉시 착수 가능 (파일/링크만 있으면 시작)

| 순서 | 모듈 | 비고 |
|---|---|---|
| 1 | 조건부 리사이징 | 1호 결과물 — 신뢰 구축 |
| 2 | 영상 분석 + 스크립트 생성 | 루브릭(기준 영상 2~3개) 합의 선행 |
| 3 | 리뷰 분석 | 엑셀 업로드 방식. 형식 정규화 계층이 정산 분석에도 재사용됨 |

W1 과 병행: `palim-automation` 모듈 골격 + `scripts/` 규약 구현 + Docker 이미지.

### W2 — 데이터 반출 경로 확정 후

판매 브리핑 (텔레그램 브릿지 재사용) · 정산 분석 · 재고 대사

### W3 — API 계정 세팅 + 기준 합의 후

인플루언서 등급표 (PoC 먼저: 유튜브 API → Business Discovery → Hashtag 제한 확인) ·
DM 초안 · SNS 리포트 · 이미지 검수(반자동)

### W4 — 데이터 축적 후

수입 예측 · 경쟁사 모니터링(구독 조건) · CS 분석 · 상세페이지 분석

## 리스크

- **판단 기준 미합의 상태로 모듈을 만들면 평가·분류가 흔들려 신뢰를 잃는다** — 기준 문서 합의가
  각 모듈의 착수 조건이다
- 경쟁사 모니터링·공개 페이지 수집은 깨지는 유형 — 유지보수 구독 없이 시작하지 않는다
- 외부 API(Meta) 정책 변동 — 등급표 모듈은 API 의존 지점을 어댑터로 격리
