## 미해결 항목

| 항목 | 상태 |
|---|---|
| **인플루언서 루브릭 정답셋 (발주사 채널 15~20개)** | 수집 필요 — 이것 없이는 등급을 대외 산출물로 쓸 수 없다 |
| 자체 카테고리 목록·시드 키워드 발주사 합의 | 초기값은 설정에 들어가 있고 화면에서 수정 가능 |
| API 키 발급 주체 (`YOUTUBE_API_KEY`·`OPENAI_API_KEY`) | 협의 필요. YouTube 는 무료, OpenAI 만 과금 |
| Docker 이미지에 `yt-dlp` 포함 | 배포 전 필수 |
| 발주사 판단 기준 수집 (분류 카테고리·루브릭·우선순위) | 협의 중 |
| AWS 계정 주체·서버 실비 청구 구조 | 협의 필요 |
| 로그인 rate limit · 2단계 인증 | 후속 — Cloudflare 설정으로 처리 예정 |

## 리스크

- **판단 기준 미합의 상태로 등급을 내보내면 신뢰를 잃는다** — 시스템은 완성됐지만 루브릭
  초기값은 검증되지 않은 추정이다. 캘리브레이션이 대외 사용의 착수 조건이다
- **자막 수집(yt-dlp)은 언제든 깨진다** — 특히 클라우드 IP 대역. 어댑터로 격리했고 실패 시
  메타+댓글 폴백이 동작하지만, 연속 차단 감시·경고는 미구현
- **OpenAI 만 과금된다** — 쿨다운·일일 상한으로 막았으나, 키를 다른 서비스와 공유하면 상한이
  우리 쪽에서만 유효하다는 점을 유의
- 경쟁사 모니터링·공개 페이지 수집은 깨지는 유형 — 유지보수 구독 없이 시작하지 않는다
- 외부 API(Meta) 정책 변동 — 인스타 연동은 어댑터로 격리
