**설계 판단을 바꿨으면 07-DECISIONS 에 항목을 추가하고, 해당 문서를 함께 고친다.**

개발자 1인이 장기간 단독 유지보수하므로, 6개월 뒤의 자신이 유일한 독자다.

서명) 후 반영한다.
