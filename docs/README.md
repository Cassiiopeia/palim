## 문서 유지 규칙

**설계 판단을 바꿨으면 07-DECISIONS 에 항목을 추가하고, 해당 문서를 함께 고친다.**

문서와 코드가 어긋나면 문서는 거짓말이 되고, 그 시점부터 아무도 믿지 않게 된다. 이 프로젝트는 개발자 1인이 장기간 단독 유지보수하므로, 6개월 뒤의 자신이 유일한 독자다.

01-REQUIREMENTS 는 **발주자와 합의한 범위**다. 구현 세부가 바뀌어도 이 문서의 기능 정의와 인수 조건은 임의로 고치지 않는다. 변경이 필요하면 발주자 협의 후 반영한다.
