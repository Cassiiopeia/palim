## 📝 개요

명세 개편(#37)으로 확정된 마케팅 모듈 「인플루언서 등급표」를 구현한다. `palim-automation` 모듈 1호 작업이다.

유튜브 공식 API 기반으로 국내 인플루언서를 발굴, 정량 지표를 수집하고, 룰 70점 + AI 30점으로 캠페인 기준 점수를 산출한다. 광고 제안 여부는 웹 화면에서 내부 심사(제안/보류/제외)로 사람이 확정한다.

핵심 문제의식:
- 광고 단가는 구독자 수를 따라가지만 실제 성과는 조회수, 반응으로 나온다 (괴리 정량화)
- 구독자는 조회수보다 늦게 붙는다 (뜨기 직전 채널을 선점하는 라이징 레이더)

## 🛠️ 작업 상세 내용

- [ ] `palim-automation` 모듈 골격 + `scripts/` 규약 구현
- [ ] 발굴 파이프라인: 키워드 검색(주력) / 수동 시드 엑셀 / KR 인기 차트 누적 / 추천 채널 확장, 재개 가능 커서 + quota ledger
- [ ] 수집: 채널/영상 통계 배치, 쇼츠 분리, 티어별 갱신 주기
- [ ] 분류: 유튜브 원본 카테고리 + AI 자체 카테고리 다중 라벨 병행 저장
- [ ] 룰 점수 70점 (실도달 14, VSR 14, 모멘텀 14, 참여율 12, 활동성 8, 안정성 8) + 배지(급락/라이징/트렌드)
- [ ] AI 점수 30점 (브랜드 안전성 12, 캠페인 적합도 10, 반응 품질 8) — evidence 필수, 입력 해시 캐시, 수동 트리거
- [ ] 자막 수집 어댑터(`TranscriptProvider`) + 실패 시 메타/댓글 폴백
- [ ] 라이징 레이더 (지수 100점 + 차익배율 + 매일 스냅샷 + 텔레그램 주간 알림)
- [ ] 트렌드 보드 (주간 키워드 빈도 비교 + 발굴 시드 환류)
- [ ] 웹 화면 5종: 등급표 / 채널 상세(심사) / 라이징 레이더 / 트렌드 보드 / 캠페인 관리
- [ ] 스코어링 설정 YAML 외부화 + 캘리브레이션 대조 지원
