## 📝 개요

#41 에서 라이징 지수(100점)는 이미 계산되어 점수 행 안에 저장되고 있으나, 보여줄 화면이 없어 활용되지 못한다. 전용 화면과 주간 알림을 붙여 "곧 뜰 채널을 단가가 오르기 전에 선점한다"는 원래 목적을 실제로 쓸 수 있게 만든다.

광고 단가는 구독자 수를 후행하고 조회수는 선행한다. 조회수가 먼저 터진 채널은 단가가 오르기 전의 차익 구간에 있으며, **이 정보는 유통기한이 있다** — 2주 늦으면 단가가 이미 올라 있다. 그래서 화면만으로는 부족하고 알림이 필요하다.

## 🛠️ 작업 상세 내용

- [ ] `rising_signal` 테이블 신설 — 지금은 점수 jsonb 안에 묻혀 있어 "라이징만 모아 보기"가 느리다
- [ ] 차익배율 계산 — 조회수 중앙값 ÷ 구독자 기반 기대 조회수. 화면 최상단에 노출할 핵심 숫자
- [ ] 라이징 레이더 화면 — 지수순 정렬, 차익배율, 감지 후 경과일, 유료광고 이력
- [ ] 주간 텔레그램 알림 — `palim-notification` Outbox 경유 (직접 봇 호출 금지)
- [ ] 성장 곡선 표시 — 라이징 채널은 매일 스냅샷이 쌓이므로 구독자·조회수 추이를 보여준다
- [ ] 라이징 해제 처리 — 성장이 꺾이면 레이더에서 자동으로 내린다
