이카운트 ERP

이카운트는 키를 두 번 받습니다. 먼저 테스트 인증키로 연결이 되는지 확인하고, 그게 확인돼야 정식 인증키를 발급받을 수 있습니다. 테스트 인증키는 유효기간이 짧아(보통 2주) 매일 가져오는 데는 쓸 수 없지만, 기간 안에서는 여러 번 확인할 수 있습니다.

  1. 이카운트에 로그인합니다
  2. Self-Customizing > 정보관리 > API인증키발급 으로 들어갑니다
  3. [키발급] 을 누르고, 뜨는 창에서 API 사용을 허용할 ID 를 고른 뒤 저장합니다
  4. 발급된 인증키를 아래 칸에 붙여 넣습니다
ONEWMS (3자물류)

별도 발급이 없습니다. 평소 화면에 로그인할 때 쓰는 계정정보(회사코드)·아이디·비밀번호 를 그대로 넣습니다.

넣기 전에 두 가지를 확인하세요
  1. 인증키는 발급할 때 고른 「사용을 허용할 ID」 에 묶입니다. 아래 「사용자 ID」 가 그 ID 와 같아야 합니다 — 다르면 로그인 단계에서 거부됩니다.
  2. 이 서버의 주소를 등록해야 합니다. 등록 위치 안내 주소를 모르면 그대로 실행하세요 — 거부되면 응답에 상대가 본 요청 주소가 찍혀 나오므로 그 값을 등록하면 됩니다.

거의 다 됐습니다 — 남은 것은 정식 인증키뿐입니다

방금 쓰신 테스트 인증키는 유효기간이 짧아(보통 2주) 매일 가져오는 데는 쓸 수 없습니다. 확인용으로는 기간 안에서 다시 쓸 수 있습니다.
매일 자동으로 가져오려면 정식 인증키가 필요합니다. 테스트 검증을 마쳤으므로 이제 발급받을 수 있습니다.
  1. 이카운트에서 정식 인증키를 발급받습니다 — 경로는 위 「발급 방법 보기」와 같습니다
  2. 칸 맞추기를 마친 뒤 정식 인증키로 바꿉니다
허용 ID 와 접속 IP 는 이미 등록되어 있어 다시 하지 않아도 됩니다.
