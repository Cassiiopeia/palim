인증키가 없으신가요? — 발급 방법 보기
이카운트 ERP
이카운트는 키를 두 번 받습니다. 먼저 테스트 인증키로 연결이 되는지 확인하고, 그게 확인돼야 정식 인증키를 발급받을 수 있습니다. 테스트 인증키는 유효기간이 짧고(보통 2주) 데이터 조회에 한 번 성공하면 더 쓸 수 없으므로, 이 화면은 한 번 실행으로 끝까지 확인합니다.
  1. 이카운트에 로그인합니다
  2. 상단 Self-Customizing → 정보관리 → API인증키발급
  3. [키발급] 을 누르고, 뜨는 창에서 API 사용을 허용할 ID 를 고른 뒤 저장합니다
  4. 발급된 인증키를 아래 칸에 붙여 넣습니다
허용 ID 를 반드시 확인하세요. 인증키는 그때 고른 ID 에 묶입니다. 아래 「사용자 ID」 가 그 ID 와 다르면 로그인 단계에서 거부됩니다.
권한이 없다고 나오면 회사 마스터 계정에게 발급을 요청해야 합니다.

거의 다 됐습니다 — 정식 인증키만 받으면 끝납니다

방금 쓰신 테스트 인증키는 이번 조회에 성공하면서 만료됐습니다. 이카운트가 그렇게 정해 둔 것이라 정상입니다. 연결에 문제가 있는 것이 아닙니다.
매일 자동으로 가져오려면 정식 인증키가 필요합니다. 테스트 검증을 마쳤으므로 이제 발급받을 수 있습니다.
  1. 이카운트 → Self-Customizing → 정보관리 → API인증키발급
  2. [키발급] 에서 정식 인증키를 발급받습니다
  3. 위에서 「정식 인증키」 를 고르고, 받은 키를 넣은 뒤 다시 누릅니다
허용 ID 와 접속 IP 는 이미 등록되어 있어 다시 하지 않아도 됩니다. 정식 키를 넣고 누르면 확인과 저장이 한 번에 끝납니다.
