← 칸 연결

받아온 값을 담기 전에 다듬습니다. 두 시스템이 같은 물건을 다르게 적을 때 (「초콜릿」 vs 「초콜렛」) 여기서 맞춰 두면 품목 맞추기에서 이어집니다.

들어오는 것과 나가야 하는 것
들어옴 {"rows": [{"_row": 1, "raw_item_name": "…", …}]}
나가야 {"rows": [{"_row": 1, "normalized_name": "…"}]}
  • _row 는 어느 줄인지 알려주는 손잡이입니다. 그대로 돌려주기만 하면 됩니다
  • 바꿀 칸만 담아 돌려주세요. 안 담은 칸은 그대로 갑니다
  • 사람에게 할 말은 stderr 로. stdout 에는 마지막 JSON 하나만
  • 어느 칸이든 바꿀 수 있습니다. 다만 꼭 필요한 칸(품목·수량·출처· 기준 시각)을 비우면 그 줄은 담기지 않고 이유가 남습니다
